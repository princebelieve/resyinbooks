# Page design plan — children's illustrated edition

## Interior look

Use the completed Resyin books as the production reference for disciplined front matter, contents, copyright metadata, separate print/digital editions, end-matter order, proofing and file organization. Use the supplied Healthy Living cover/chapter sheet as a visual reference for this title's brighter child-facing art direction; do not transplant the unrelated WAEC art.

- **Print:** portrait A5, colour interior, generous margins and sturdy page rhythm. Reconfirm printer-specific paper, bleed and binding before the wrap is calculated.
- **Digital fixed-page PDF:** A4 reading edition, with large text and comfortable image scale. The reflowable EPUB will not be described as A4/A5.
- **Typography:** large, highly legible body text; clear title/subtitle hierarchy; semantic heading styles; short paragraphs and generous line spacing. Keep activity instructions visually separate from lesson text.
- **Chapter openers:** bold chapter number, large title and one original full-page/large half-page illustration. Use a recurring palette of leaf green, navy, warm yellow and coral drawn from the supplied title art.
- **Learning features:** consistent but varied “Think about it,” “Try this,” “Remember,” and promise panels. Use icons as supporting navigation only, not as substitutes for accessible labels.
- **Illustrations:** one specific full-resolution scene for each chapter, with smaller activity/spot art only where it helps understanding. Each image gets useful alt text in digital editions. No text is generated inside the artwork.
- **Front/back matter:** title page, approved copyright page, contents, dedication/preface/parent note, ten chapters, conclusion, pledge, reflection tracker, glossary, references and author bio. If an index is added, it goes after all other end matter.
- **Cover:** preserve the source wrap as reference. Verify/replace its invalid ISBN and rebuild the spine from the final page count using the selected printer's template. Omit testimonial/endorsement copy as requested; there are no named testimonials on the Healthy Living source wrap, only one generic quotation, so the final back-cover treatment will leave out endorsement copy entirely.

The illustration briefs define each image's story and composition. Do not place raster or unrelated cached artwork into the book just to fill an image slot.

The ten-panel illustration board is treated as chapter-specific source material. Its ten uncropped originals are preserved; separate native-size crops are in Illustration_References for composition reference. See Illustrated_Board_Analysis.md for the lesson/art map.

A styled A5 HTML review prototype now uses the supplied front-only cover crop and one storyboard panel per chapter. It demonstrates the child-facing hierarchy and color system while the final high-resolution art is prepared. The source cards have tiny embedded text and are explicitly labeled as temporary references.
