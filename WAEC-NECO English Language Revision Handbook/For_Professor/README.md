# Files for Prof - review draft

This folder contains review copies, not finished publication files:

- `WAEC_NECO_English_Language_Revision_Handbook_Editorial_Review_Draft.docx` — editable 16-chapter manuscript with a hierarchical Contents table, dotted leaders and page numbers. In Word, update the whole table (References → Update Table → Update entire table) after any pagination or text change.
- `WAEC_NECO_English_Language_Revision_Handbook_Review_Draft_A5.pdf` — A5 print-layout review proof with a chapter-level Contents page showing dotted leaders and actual page numbers, plus numbered page footers; not printer-ready.
- `WAEC_NECO_English_Language_Revision_Handbook_Two_Up_Review.pdf` — consecutive A5 pages imposed side by side on A4 landscape sheets for print review.
- `WAEC_NECO_English_Language_Revision_Handbook_Review_Draft_A4.pdf` — A4 reading-layout review proof with a standalone front-cover image, chapter page locators, and numbered page footers.
- `The_Complete_WAEC_NECO_English_Language_Revision_Handbook.epub` — reflowable EPUB 3 with navigation; validated with EPUBCheck 5.4.0 (no errors or warnings).
- `WAEC_NECO_English_Language_Cover_Front_Review.jpeg` — standalone front-cover review image.
- `WAEC_NECO_English_Language_Cover_Wrap_Without_Testimonials_Review.jpeg` — redesigned full-wrap review image. The back panel replaces testimonials with a book description, subject coverage and accurate feature list. Unsupported syllabus, ISBN/barcode, and guaranteed-grade claims have been removed or reserved for publisher review.

EPUB validation output is retained at `../Codex_Working_Files/Production/EPUB_Validation/epubcheck.txt`. The two-up proof can be regenerated with `../Codex_Working_Files/Production/build_two_up.py` using the retained local PyMuPDF installation.

The source cover and Chapters Two-Sixteen remain unchanged in `../Professor_Supplied/`. Chapter One and the complete original-practice mock examinations were drafted for this review edition. The book title, contents, examination claims, imprint, author credential and ISBN require editorial/publisher review before publication. The interior page count, trim, binding, bleed, paper and printer template have not been established, so the cover image is not a printer-ready wrap. The PDFs list chapter-level page locators; the Word Contents table also lists subsection headings. The two-up file is a layout proof only; the publisher/printer must confirm imposition, stock and binding before production. A subject index is not included in this review set.
