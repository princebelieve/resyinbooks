# WAEC/NECO English Language Revision Handbook

New project created from the supplied recovered outline, chapter drafts and cover artwork. The source files are preserved unchanged in `Professor_Supplied/`. Chapter One is drafted in `Codex_Working_Files/Working_Manuscript/`, and `For_Professor/` contains a cover review copy with the back-cover testimonials removed.

The folder arrangement follows the Resyin Books production pattern: originals in `Professor_Supplied/`, editorial and build records in `Codex_Working_Files/`, and professor-facing review/final files in `For_Professor/`.
