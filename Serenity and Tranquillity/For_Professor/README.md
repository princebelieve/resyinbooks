# Files for Prof

This folder contains one copy of each current deliverable: the reflowable EPUB, digital reading PDF, A5 print interior PDF, two-up PDF, editable indexed Word manuscript and standalone front-cover JPEG.

The A5 print interior uses 11 pt body text and an 11 pt, two-page, one-column Contents with all 25 chapter titles and opening page numbers. The A5 and two-up files are print-only; the A4 PDF and EPUB provide digital navigation.

There is no current full-wrap print cover in this package. The print provider's template and paper/binding specifications are needed to prepare one for the 346-page interior.
