# Subject index review

The previous subject index contained topic associations but no page locators. It also combined several entries in each paragraph. It has been replaced in the indexed editions with an alphabetical two-column index, letter headings, subordinate entries, cross-references, and edition-specific page locators.

Locators identify the substantive retained manuscript sections, including continuation pages. They exclude the contents, bibliography, glossary and index. Selected additional terms (including artificial intelligence) are located directly in chapter text. See Subject_Index_Audit.json for the entry-to-section/page mapping.

- Serenity_and_Tranquillity_Print_Interior_A5_Indexed.pdf: 345 pages; index begins on page 339, occupying 7 pages; 266 topic/subtopic entries plus 11 cross-references.
- Serenity_and_Tranquillity_Digital_Readable_Indexed.pdf: 229 pages; index begins on page 225, occupying 5 pages; 266 topic/subtopic entries plus 11 cross-references.

All printed index numbers (including both ends of ranges) are clickable in the one-page PDFs and the two-up print PDF. See references lead to their corresponding index entries. The digital PDF also has selective underlined topic links to substantive section discussions and a Subject index return link on chapter pages. Use your PDF reader’s Back/Previous View command to return to the previous reading location.

Link destinations and rectangles were checked after reopening each saved one-page PDF. Every index row and column width was checked. Chapter text and pagination were preserved; the digital edition adds a small navigation control to the footer. All remaining end matter precedes the index, which is now the final section. Original editions are retained in Archive_Obsolete.

The indexed DOCX contains hidden XE index markers and a native Word INDEX field. Open it in Word, select all, and press F9 to populate its own page numbers. Its locators must not be copied from either PDF. Interactive navigation is supplied in the PDFs.

The previous print cover is sized for 339 pages. The indexed interior has a new page count, so its cover spine must be resized using the printer’s paper specification before print upload. The two-up PDF is a reading/printing spread, not booklet imposition.
