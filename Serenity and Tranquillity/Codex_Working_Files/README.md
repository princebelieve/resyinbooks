# Codex working files

This folder contains the build process, retained layout baselines, reports, previews and local production tools. Files intended to be shared with Prof are grouped separately in `../For_Professor`.

- `Source_Baselines` contains the three prior working editions required by `build_subject_index.py`; they are not current deliverables.
- `build_subject_index.py` creates the indexed PDFs, two-up PDF and editable indexed DOCX in `../For_Professor`.
- `build_epub.py` builds the EPUB there from the indexed Word file and front-cover JPEG.
- `EPUB_Validation`, `Previews`, production notes and audit files record the completed workflow.
- `.python_libs` and `.tools` retain PyMuPDF and EPUBCheck locally so future production does not need to download them again.

The original references for this title were not recorded as source files. The retained baselines are Codex working inputs, not a complete archive of Prof's supplied references.
