# Subject index review

The previous subject index contained topic associations but no page locators. It also combined several entries in each paragraph. It has been replaced in the indexed editions with an alphabetical two-column index, letter headings, subordinate entries, cross-references, and edition-specific page locators.

Locators identify the substantive retained manuscript sections, including continuation pages. They exclude the contents, bibliography, glossary and index. Selected additional terms (including artificial intelligence) are located directly in chapter text. See Subject_Index_Audit.json for the entry-to-section/page mapping.

- Serenity_and_Tranquillity_Print_Interior_A5_Indexed.pdf: 346 pages; index begins on page 340, occupying 7 pages; 266 topic/subtopic entries plus 11 cross-references.
- Serenity_and_Tranquillity_Digital_Readable_Indexed.pdf: 230 pages; index begins on page 226, occupying 5 pages; 266 topic/subtopic entries plus 11 cross-references.

The printed editions show index locators as text. The digital PDF has clickable index numbers, See references, selective topic links and a return-to-index control on chapter pages. Use the PDF reader Back/Previous View command to return to the prior reading location.

Link destinations are checked after saving the digital PDF. The print and digital PDFs are checked separately for page size and index layout. Chapter text is retained; the expanded Contents shifts downstream page numbers, which are recalculated for each format. Back matter follows the index. Original source baselines are retained.

The indexed DOCX contains hidden XE index markers and a native Word INDEX field. Open it in Word, select all, and press F9 to populate its page numbers. Its locators must not be copied from either PDF.

No current full-wrap print cover is available. Obtain the selected printer template and paper/binding specifications before producing one. The two-up PDF is a print spread, not booklet imposition.
