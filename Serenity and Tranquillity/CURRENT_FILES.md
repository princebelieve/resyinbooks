# Final files for *Serenity and Tranquillity*

Start here. [For_Professor](For_Professor/README.md) contains the deliverables to share; [Codex_Working_Files](Codex_Working_Files/README.md) contains the builders, baselines, production notes, audits, validation reports, previews and local tools. The original Serenity references supplied to Codex were not recorded as source files; three retained layout baselines are identified inside the Codex folder. The shared workflow is in [Book_Production_Workflow.md](../Book_Production_Workflow.md).

The A5 body text and the two-page Contents in both PDFs are 11 pt; the A4 digital PDF body text is 11.5 pt. The digital PDF has 230 pages; its linked subject index is at the end on pages 226–230. The reflowable EPUB has a single-column navigation list that adapts to phone screens. The supplied print ISBN failed its checksum, so no replacement ISBN was invented. The standalone front-cover JPEG is in For_Professor; no current full-wrap print cover is available. Original layout baselines and the separate TOC-expanded rebuild inputs are retained in Codex_Working_Files/Source_Baselines.
