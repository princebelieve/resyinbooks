# Production working files

This folder preserves the material used to produce the current book editions. The project-root folder contains the final usable copies, as in the *Serenity and Tranquillity* project.

- `Source_Materials` contains Prof's supplied text and original cover artwork; these are retained unchanged.
- `Working_Manuscript` contains the source assembly, editable base manuscript, EPUB and editorial audits.
- `Production` contains print/digital intermediates, cover source proof, indexes, audits, validation reports and previews.
- The build scripts are kept here so the package remains reproducible. Run them from this folder in their documented order in `Production_Notes.md`.
- Older top-level preview/validation folders and Python cache are also retained here.

The source and build materials were moved here, not deleted. The root `CURRENT_FILES.md` is the index to the deliverables for reading, review and printing.
