# Subject index and navigation

The subject index is specific to this manuscript. Locators are derived from the selected numbered chapter sections listed in `Subject_Index_Audit.json`; the index follows all supplied back matter at the end of each PDF. Index locators, See references, contents links, chapter bookmarks and digital related-topic links are internal PDF links. The two-up A5 file preserves these destinations across imposition.

The index is a first editorial pass and should be reviewed for scope and terminology. Each locator points to the start of a relevant section; it does not imply that every passing mention is indexed.
