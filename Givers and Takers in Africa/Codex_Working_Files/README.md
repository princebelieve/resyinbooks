# Codex working files

This folder contains the book-building files only. Prof's supplied materials are grouped separately in `../Professor_Supplied`. Files intended to be shared with Prof are grouped in `../For_Professor`.

- `Working_Manuscript` contains the assembled manuscript, editable base file, source extract and editorial audit trail.
- `Production` contains base layouts, indexes, validation reports, previews and the print-cover audit. The corresponding 167-page wrap proof is in `../For_Professor` for review.
- The scripts in this folder rebuild the book. Run them from this directory, in the sequence recorded in `Production_Notes.md`.
- Local Python and EPUBCheck dependencies are retained in `../../Serenity and Tranquillity/Codex_Working_Files` and are not downloaded by the rebuild sequence.

The only full-wrap image intended for review is in `../For_Professor` and is explicitly labeled as a cream-paper assumption proof, not a printer-ready cover.
